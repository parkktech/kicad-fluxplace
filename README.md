# fluxplace

Place, route, review, fab for KiCad 10.

**AI agents: read only [AGENTS.md](AGENTS.md).** Detail: `fluxplace help-brief CMD`.

## Install ([INSTALL](docs/INSTALL.md))

    pip install -e .
    fluxplace doctor      # missing deps

## Pipeline

`fluxplace pipeline BOARD --constraints C --spec S --workdir W` runs staged (`W/state.json`). [Agent briefs](docs/AGENT-PIPELINE.md)

Output: [output.md](docs/commands/output.md).
